Totally Real Third-Party Site

This static page is a throwaway dev smoke test, not a product deliverable. It stands in for an arbitrary customer's website that has embedded our chat widget via a single <script> tag, the same way a real customer would. There is no build step or framework here — just this plain HTML file, served as a static asset by the app's own Next.js server.
